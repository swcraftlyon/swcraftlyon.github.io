## Rétro

- Difficile de prendre le wagon en cours de route ;
- En mode découverte, je comprends mieux comment marchent les katas, j'espère être plus proactif la prochaine fois ;
- Le kata n'est pas facile, c'est un sac de nœuds qui demande de savoir ce qu'est l'approval testing, il y a du random, ce n'est pas spécialement un kata débutant ;
- Le kata semblait nul au début, puis quand ça s'est décoincé il révèle sa puissance : il permet d'aborder la notion de code non testable à rendre testable ;
- En tant que driver, le kata est horrible : le setup est mauvais et à retravailler, les assertions sont difficiles à comprendre et peuvent faire passer à côté du sujet, les sorties d'expectation sont illisibles ;
- Ça peut valoir le coup de mettre à jour le setup : réparer le coverage, rendre les choses visibles, améliorer l'utilisation d'approval ;
- Merci pour le provider.
